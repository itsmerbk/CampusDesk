# CampusDesk

**Anti-Cheating Exam Hall Seat Allocator & Live Invigilator Attendance Console (Java 21 + Vanilla JavaScript)**

CampusDesk uses a graph-coloring seat-interleaving algorithm in Java 21 to ensure zero horizontally or vertically adjacent students share the same exam subject, backed by SQLite WAL persistence and a live invigilator attendance grid.
